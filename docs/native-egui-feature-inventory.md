# Native egui feature inventory

The eframe desktop is implemented alongside the React/Tauri desktop and iOS app. This table reports source presence separately from tested behavior. The current immutable native build, interaction evidence, and limits are recorded in [native-egui-acceptance.md](native-egui-acceptance.md); snapshot 12 is the current packaged build, and snapshot 11 carries the full native test suite and most interaction evidence.

## Evidence boundary

For each interaction claim, acceptance evidence binds the immutable executable, process, isolated data directory, backend, display, action, and result. Source presence, a Rust test, package parse, accessibility tree, or screenshot alone does not prove a complete interaction. Do not use the installed Tauri application as evidence for eframe behavior or promote older snapshot results to snapshot 11.

The current limits are explicit: Linux X11 only; no Wayland/macOS/Windows, GPU acceleration, IME composition, screen-reader, or microphone acceptance; no accepted 100,000-line diff timing; no Arabic file-preview claim; no real Codex Stop-interruption claim; and terminal child shutdown on app exit is not accepted. Snapshot 12 contains one Windows-only `Start-Process -FilePath` correction and passed native all-target check; its Linux GUI hash changed after relink, so evidence is assigned to its recorded snapshot-specific binary. Snapshot-12 keyboard option selection passed for Model/Mode locally and through the daemon and for daemon Effort; local Effort passed on snapshot 11. A full keyboard-only navigation path from startup is not claimed. See the [acceptance record](native-egui-acceptance.md) for evidence paths and detailed results.
